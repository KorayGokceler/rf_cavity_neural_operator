# A posteriori error estimators for the Maxwell eigenvalue problem (Nédélec / H(curl), PEC cavity)

Notation used below (follows the cited papers): E_h ∈ N_h ⊂ H0(curl), ω_h² = λ_h the discrete eigenvalue, ||E_h||_0 = 1;
F_I(K) = interior faces of tetrahedron K; [[·]] = jump across a face; h_K, h_F = element / face diameters.
"Proven" = theorem in the cited paper; "observed" = numerical evidence only.

## 1. Residual-based estimators: exact terms, the divergence / normal-jump terms, reliability, efficiency, p-dependence

### Takeaway
The standard (proven) residual estimator for the Maxwell eigenproblem with Nédélec elements has four terms: the element residual of the curl-curl equation, the tangential jump of curl E_h, and, because of the gradient kernel, the element divergence and the normal jump of E_h. There are no PEC-wall terms: only interior faces appear. It gives ||E − E_h||_curl ≤ Cμ and |λ − λ_h| ≤ Cμ² for h small enough, and it is locally efficient (Boffi–Gastaldi–Rodríguez–Šebestová, J. Sci. Comput. 2019). In 3D Fichera tests with lowest-order elements, the normal-jump (kernel) term made up about 80% of the estimator, so it cannot be dropped. Residual-estimator constants depend on p (Bürg derived explicit hp bounds). p-robust bounds need equilibration (section 2).

### Cited Findings
**Boffi, Gastaldi, Rodríguez, Šebestová (BGRS), "A posteriori error estimates for Maxwell's eigenvalue problem", J. Sci. Comput. 78 (2019) 1250–1271, DOI 10.1007/s10915-018-0808-5 (preprint CI²MA 2017-15). This is the H(curl)-norm estimator.**
- Local indicator, verbatim structure (eq. (5)): μ_K² = h_K² ||E_h − curl curl E_h / ω_h²||²_{0,K} + h_K² ||div E_h||²_{0,K} + ½ Σ_{F∈F_I(K)} [ h_F ||[[ (curl E_h / ω_h²) × n ]]||²_{0,F} + h_F ||[[E_h · n]]||²_{0,F} ], with μ² = Σ_K μ_K². The sums run only over inner faces F_I(K), so there is no boundary (PEC) term — [BGRS 2019 preprint](https://ci2ma.udec.cl/pdf/pre-publicaciones2/2017/pp17-15.pdf)
- The analysis goes through the equivalent mixed problem with u = ωE and σ = curl E/ω. The mixed indicator is η_K² = h_K²||u_h + curl σ_h||² + h_K²||div u_h||² + ½Σ_F(h_F||[[σ_h × n]]||² + h_F||[[u_h·n]]||²), with μ_K² = η_K²/λ_h — [BGRS 2019 preprint](https://ci2ma.udec.cl/pdf/pre-publicaciones2/2017/pp17-15.pdf)
- Reliability (Theorem 3): ||u − u_h||_0 + ||σ − σ_h||_0 ≤ C1 η + C2 ρ(h)(||u − u_h||_0 + ||σ − σ_h||_0), with ρ(h) → 0. The consequence is ||E − E_h||_curl ≤ Cμ + C'μ² and |ω − ω_h| = |λ − λ_h|/(ω + ω_h) ≤ C η² = (C/ω_h²) μ² for h small enough. The analysis is for simple eigenvalues, and the authors say it extends to multiple eigenvalues and clusters "in the spirit of" the cluster paper. The proof uses a Helmholtz decomposition u − u_h = ∇α + curl β, where the ∇α part is controlled with a Scott–Zhang interpolant of α (gradients of P1 functions lie in the Nédélec space), and a superconvergence lemma — [BGRS 2019 preprint](https://ci2ma.udec.cl/pdf/pre-publicaciones2/2017/pp17-15.pdf)
- Efficiency (Theorem 4, local): h_K||div u_h||_{0,K} ≤ C||u − u_h||_{0,K}; h_K||u_h + curl σ_h||_{0,K} ≤ C(h_K||u − u_h||_{0,K} + ||σ − σ_h||_{0,K}); h_F^{1/2}||[[u_h·n]]||_F ≤ C||u − u_h||_{0,ω_F}; h_F^{1/2}||[[σ_h × n]]||_F ≤ C(h_F||u − u_h||_{0,ω_F} + ||σ − σ_h||_{0,ω_F}); hence η_K ≤ C(||u − u_h||_{0,ω̃_K} + ||σ − σ_h||_{0,ω̃_K}). The authors note that efficiency for eigenproblems is less local, because it involves the global quantity ω − ω_h — [BGRS 2019 preprint](https://ci2ma.udec.cl/pdf/pre-publicaciones2/2017/pp17-15.pdf); [Boffi–Gastaldi arXiv 1804.02377](https://arxiv.org/pdf/1804.02377)
- The 2019 paper improves on the 2017 L²-norm estimator "by adding suitable (quite natural) terms to the error indicator, thus avoiding the introduction of the higher order terms in the error analysis" — [BGRS 2019 preprint](https://ci2ma.udec.cl/pdf/pre-publicaciones2/2017/pp17-15.pdf)
- For lowest-order edge elements, div E_h = 0 and curl curl E_h = 0 element-wise, so μ_K² = h_K²||E_h||²_K + ½Σ_F[(h_F/ω_h⁴)||[[curl E_h × n]]||²_F + h_F||[[E_h·n]]||²_F] — [BGRS 2019 preprint](https://ci2ma.udec.cl/pdf/pre-publicaciones2/2017/pp17-15.pdf)
- Measured share of each term (Fichera domain (−1,1)³∖[−1,0]³, first eigenvalue ω² ≈ 3.220): element term ≈ 8.5% of μ², tangential curl jump ≈ 11.5%, normal jump of E_h ≈ 80%. Effectivity indices (μ² against the eigenvalue error) stayed between 5.18 and 6.25, except on the coarsest meshes — [BGRS 2019 preprint](https://ci2ma.udec.cl/pdf/pre-publicaciones2/2017/pp17-15.pdf)

**BGRS, "Residual-based a posteriori error estimation for the Maxwell's eigenvalue problem", IMA J. Numer. Anal. 37(4) (2017) 1710–1732, DOI 10.1093/imanum/drw066, arXiv 1602.00675. This is the L²-norm estimator.**
- Indicator: η_K² = h_K²||div u_h||²_{0,K} + Σ_{F∈F_h^I, F⊂∂K} (h_F/4)||[[u_h·n_F]]||²_{0,F}. It contains only the "kernel" terms. Theorem 4.1: ||u − u_h||_0 ≤ C(η + h^{2t}), with 1/2 < t < 1 the regularity index. The h^{2t} term is higher order for k = 0, and for higher-order elements only when the eigenfunction is singular. Theorem 4.2 gives local efficiency via bubble functions — [arXiv 1602.00675](https://arxiv.org/pdf/1602.00675)
- Role of the divergence/normal-jump terms, from the proof of Lemma 4.1: the discrete eigenfunction is discretely divergence-free, (u_h, ∇(I_C α)) = 0, and the exact one satisfies (u, ∇α) = 0. So (e_h, ∇α) = −(u_h, ∇(α − I_C α)) = Σ_K (div u_h, α − I_Cα)_K − Σ_F ½([[u_h·n_F]], α − I_Cα)_F. The gradient component of the error is measured exactly by the element divergence and the normal jumps — [arXiv 1602.00675](https://arxiv.org/pdf/1602.00675)
- The authors state that before their work, "no results on a posteriori error estimation of Maxwell's eigenvalue problem are available in the literature" — [arXiv 1602.00675](https://arxiv.org/pdf/1602.00675)

**Source-problem antecedent: Beck, Hiptmair, Hoppe, Wohlmuth, "Residual based a posteriori error estimators for eddy current computation", M2AN 34(1) (2000) 159–182, DOI 10.1051/m2an:2000136.**
- Problem: (χ curl u, curl q) + (βu, q) = (f, q) with div f = 0. A β-orthogonal Helmholtz-type splitting H0(curl) = ker(curl) ⊕ H⊥ estimates the irrotational and the solenoidal error separately — [Beck et al. 2000 (Augsburg OA)](https://opus.bibliothek.uni-augsburg.de/opus4/files/57039/57039.pdf)
- Irrotational part (the residual tested with grad H¹₀, using div f = 0): η0_T = h_T ||β^{-1/2} div(βũ_h)||_T and η0_F = h_F^{1/2} ||β_A^{-1/2} [n·βũ_h]_J||_F. Solenoidal part: η1;1_T = h_T ||χ^{-1/2}(π_h f − curl χ curl ũ_h − βũ_h)||_T, the oscillation η1;2_T = h_T||χ^{-1/2}(f − π_h f)||_T, and η1_F = h_F^{1/2}||χ_A^{-1/2}[n × χ curl ũ_h]_J||_F, over interior faces only. Theorem 4: γ1η1 − γ2η2 ≤ ||e||_E ≤ Γ1(η1 + η2) + Γ2 η_it, with constants depending on Ω, χ, β and the shape regularity of the initial mesh — [Beck et al. 2000](https://opus.bibliothek.uni-augsburg.de/opus4/files/57039/57039.pdf)
- For lowest-order edge elements, χ curl ũ_h is element-wise constant and the estimator simplifies to h_T²||π_h f − βũ_h||² plus the normal and tangential face jumps (their eq. (18)) — [Beck et al. 2000](https://opus.bibliothek.uni-augsburg.de/opus4/files/57039/57039.pdf)
- Cai & Cao summarise this structure as "four types of errors": an element residual and a face jump for the equation, plus an element residual and a face jump "associated with the divergence of the original equation: ∇·(βu) = ∇·f" — [Cai–Cao arXiv 1504.00898](https://arxiv.org/pdf/1504.00898)

**Lipschitz domains, hp, other residual variants**
- Schöberl, "A posteriori error estimates for Maxwell equations", Math. Comp. 77 (2008) 633–649, DOI 10.1090/S0025-5718-07-02030-3: proves reliability of the Beck et al. estimator on general Lipschitz domains, where Beck et al. needed extra domain assumptions. The tool is new error estimates for commuting quasi-interpolation operators — [AMS page](https://www.ams.org/mcom/2008-77-262/S0025-5718-07-02030-3/)
- Earlier residual analyses: Monk (1998, JCAM) for scattering and Beck et al. (2000) for eddy currents assumed smooth coefficients and sufficiently regular domains. Nicaise & Creusé (2003) treated piecewise-constant coefficients. Cochez-Dhondt & Nicaise (2007) obtained coefficient-robust estimates. Chen et al. (2007) treated time-harmonic Maxwell with strong singularities. All as surveyed by BGRS — [arXiv 1602.00675](https://arxiv.org/pdf/1602.00675)
- hp: Bürg (2011, 2012) derived residual bounds with explicit dependence on p, and Bürg (2013) proved convergence of an hp-adaptive strategy — [arXiv 1602.00675](https://arxiv.org/pdf/1602.00675); the KIT preprint proves hp-efficiency of a residual estimator for the electric-field formulation — [KIT preprint 11/05](https://publikationen.bibliothek.kit.edu/1000024900/1910008)
- For residual-type estimators "the efficiency constant typically depends on the polynomial degree, so the upper bound is usually not very tight for high-order elements" (Chaumont-Frelet's motivation for equilibration) — [arXiv 2402.17309 via ar5iv](https://ar5iv.labs.arxiv.org/html/2402.17309)
- Also exist: an a posteriori estimator for DG discretisations of the Maxwell eigenproblem (reliability proven) — [CAMWA 2024, S0898122124004693](https://www.sciencedirect.com/science/article/abs/pii/S0898122124004693)

### Inferences
- Signs and roles. The element residual for the eigenproblem is the source-problem residual f − curl curl u_h − βu_h with f = 0 and β = −ω_h² (indefinite). BGRS rescale it by 1/ω_h², which gives E_h − curl curl E_h/ω_h². The divergence terms are the residual tested with discrete gradients ∇H¹₀. They vanish against discrete gradients (discrete Gauss law), but not against continuous gradients, so they measure the spurious gradient part of E − E_h. All terms enter squared, so no term has a sign that can cancel another.
- No PEC-wall term is needed in any of these estimators: the test functions (in H0(curl), and ∇ of H¹₀) have zero tangential trace, or vanish, on ∂Ω, so boundary faces drop out. This assumes the discrete wall coincides with the true wall (polyhedral Ω); see section 4.
- The 80% share of the normal-jump term in BGRS 2019 (lowest order) supports keeping the kernel terms in an adaptive driver. Using only curl-jump and element-residual terms (or only E/curl E recovery) is unproven for the eigenproblem.
- In the project's p2/p3 setting, div E_h ≠ 0 element-wise and curl curl E_h ≠ 0, so all four BGRS terms are non-trivial and cheap to evaluate (element and face integrals).

### Gaps
- The exact p-exponents in Bürg's hp bounds were not retrieved (the papers were not opened). No p-explicit result for the eigenvalue estimator was found; the BGRS papers state constants independent of h only, and their numerical tests use lowest order.
- Monk's book (2003) and Monk (1998) were not opened; their estimator forms are not quoted here.
- No Dai–Xu–Zhou paper specific to Maxwell was found. Dai, Xu, Zhou, Numer. Math. 110 (2008) 313–355 covers second-order elliptic eigenproblems, not Maxwell: it proves AFEM convergence and optimal complexity via the link to boundary-value approximation — [PSU record](https://pure.psu.edu/en/publications/convergence-and-optimal-complexity-of-adaptive-finite-element-eig/)

## 2. Equilibrated / flux-reconstruction estimators and guaranteed (constant-free) eigenvalue bounds

### Takeaway
For the curl-curl source problem there are mature guaranteed, constant-free, p-robust equilibrated estimators: Braess–Schöberl 2008, Gedicke–Geevers–Perugia(–Schöberl), Chaumont-Frelet–Ern–Vohralík 2022 and Chaumont-Frelet–Vohralík 2023. They are built from local vertex-patch minimisations. I found no equilibrated estimator analysed for the Maxwell eigenproblem itself. The Cancès–Dusson–Maday–Stamm–Vohralík guaranteed eigenvalue framework covers second-order elliptic operators, not Maxwell. Guaranteed lower bounds for Maxwell eigenvalues exist (Gallistl–Olkhovskiy) but are limited to lowest order and quasi-uniform meshes, and in 3D they are numerically useless (the authors' own words: "very limited"). Barrenechea–Boulton–Boussaïd give certified two-sided enclosures with Lagrange elements, at the cost of solving shifted problems.

### Cited Findings
- Braess & Schöberl (2008) analysed equilibrated-flux estimates for edge elements that need only local problems (Math. Comp. 77 (2008); cited by BGRS). Functional-type (Repin 2007, Hannukainen 2008) estimates need a global auxiliary problem — [arXiv 1602.00675](https://arxiv.org/pdf/1602.00675)
- Gedicke, Geevers, Perugia, Schöberl, "A polynomial-degree-robust a posteriori error estimator for Nédélec discretizations of magnetostatic problems" (arXiv 2004.08323, v2 May 2021): an equilibration-based estimator for arbitrary-degree Nédélec elements with an added gradient correction. Reliability constant 1 (guaranteed upper bound); efficiency constant independent of p; 3D tests. The earlier arbitrary-order version is Gedicke–Geevers–Perugia, J. Sci. Comput. 83 (2020) — [arXiv 2004.08323](https://arxiv.org/abs/2004.08323)
- Chaumont-Frelet, Ern, Vohralík, "Stable broken H(curl) polynomial extensions and p-robust a posteriori error estimates by broken patchwise equilibration for the curl-curl problem", Math. Comp. 91 (2022) 37–74, arXiv 2005.14537: minimisers over piecewise polynomials with prescribed tangential jumps and element curls are bounded by the broken H(curl) minimisers with p-independent constants — [arXiv 2005.14537](https://arxiv.org/pdf/2005.14537)
- Chaumont-Frelet & Vohralík, "p-robust equilibrated flux reconstruction in H(curl) based on local minimizations: application to a posteriori analysis of the curl-curl problem", SIAM J. Numer. Anal. 61 (2023) 1783–1818, DOI 10.1137/21M141909X, arXiv 2105.07770: minimisations in vertex patches give "guaranteed, fully computable, constant-free, and polynomial-degree-robust a posteriori error estimates of Prager–Synge type" for Nédélec elements of any degree p ≥ 0 — [SIAM DOI](https://doi.org/10.1137/21M141909X); [arXiv 2105.07770](https://arxiv.org/pdf/2105.07770)
- Chaumont-Frelet, "A simple equilibration procedure leading to polynomial-degree-robust a posteriori error estimators for the curl-curl problem", Math. Comp. 92 (2023), arXiv 2108.07552 — [arXiv 2108.07552](https://arxiv.org/pdf/2108.07552)
- Chaumont-Frelet, "Asymptotically constant-free and polynomial-degree-robust a posteriori error estimates for time-harmonic Maxwell's equations" (arXiv 2402.17309, Feb 2024; Numer. Math. 2025, DOI 10.1007/s00211-025-01519-x). The electric displacement (divergence constraint) and the magnetic field (curl constraint) are reconstructed locally. The reliability constant tends to 1 as h → 0 and/or p grows (asymptotic, not guaranteed). Efficiency is p-independent. Robust at low frequency — [arXiv 2402.17309](https://arxiv.org/abs/2402.17309); [Springer](https://link.springer.com/article/10.1007/s00211-025-01519-x)
- Chaumont-Frelet & Vega, "Frequency-explicit a posteriori error estimates for finite element discretizations of Maxwell's equations", SIAM J. Numer. Anal. (2022), DOI 10.1137/21M1421805 — [SIAM](https://epubs.siam.org/doi/10.1137/21M1421805)
- Cancès, Dusson, Maday, Stamm, Vohralík, "Guaranteed a posteriori bounds for eigenvalues and eigenvectors: multiplicities and clusters", Math. Comp. 89 (2020) 2563–2611. For second-order self-adjoint elliptic operators with compact resolvent: guaranteed bounds on the sum of the cluster eigenvalues and on the density-matrix error, under the sole assumption that the cluster is separated from the eigenvalues below and above, which can be checked numerically. Earlier: SIAM 2017 (conforming) and Numer. Math. 2018 (unified framework, simple eigenvalues) — [AMS](https://www.ams.org/journals/mcom/2020-89-326/S0025-5718-2020-03549-2)
- Gallistl & Olkhovskiy, "Computational lower bounds of the Maxwell eigenvalues", arXiv 2110.02605 (v3 Nov 2022). This generalises Liu–Oishi to Maxwell. The guaranteed lower bound is λ_h/(1 + M̂_h² λ_h) ≤ λ, where M̂_h bounds the Galerkin error of the source problem, ||u − u_h||_a ≤ M_h||f||_b. M̂_h combines a hypercircle principle, an auxiliary global eigenproblem, and computable stability bounds of the Falk–Winther commuting projection (local discrete eigenproblems). For nonconforming (discretely divergence-free) spaces "no monotonicity principles are applicable for a comparison of discrete and true eigenvalues". M_h ~ h^s with s ≤ 1 "limits efficient computations to the case of lowest-order Nédélec (edge) elements". The method "does not immediately generalize to adaptive meshes", and "the practical use of the bounds provided by the method in three dimensions is very limited" — [arXiv 2110.02605](https://arxiv.org/pdf/2110.02605)
- Gallistl–Olkhovskiy, unit-cube test (λ1 = 2π² ≈ 19.7392), Table 6 (my reading of the columns): at h/√2 = 2⁻⁴ the discrete eigenvalue is 19.7600 and the guaranteed lower bound is 2.26e-9. At 2⁻¹ the values are 20.7306 and 3.53e-11 — [arXiv 2110.02605](https://arxiv.org/pdf/2110.02605)
- Barrenechea, Boulton, Boussaïd, "Finite element eigenvalue enclosures for the Maxwell operator", SIAM J. Sci. Comput. 36 (2014) A2887–A2906, DOI 10.1137/140957810. Uses the Zimmermann–Mertins extension of Lehmann–Maehly–Goerisch: pollution-free complementary bounds for the eigenfrequencies adjacent to a shift t, certified "in a suitable asymptotic regime", with Lagrange elements. Fichera test (0,π)³∖[0,π/2]³: first 15 eigenfrequencies enclosed with tolerance δ = 0.03 on a mesh refined along the re-entrant edges (347,460 DOF); several indices are much tighter (e.g. ω2 ∈ [1.54391228, 1.54392233]). Choosing t_up and t_low far from ω helps more than enlarging the trial space — [Strathprints PDF](https://strathprints.strath.ac.uk/50866/1/Barrenechea_etal_SIAMJSC_2014_Finite_element_eigenvalue_enclosures.pdf)
- Liu & Plum (arXiv 2512.23182, Dec 2025): a two-stage high-order FEM with Lehmann–Goerisch that gives lower bounds "as sharp as" the high-order upper bounds on graded meshes, tested only on Laplace/Steklov in 2D (no Maxwell) — [arXiv 2512.23182](https://arxiv.org/abs/2512.23182)
- Weak Galerkin (Li & Zhai, arXiv 2405.13423, 2024) proves an asymptotic lower-bound property for Maxwell eigenvalues. This is not a computable guaranteed bound — [arXiv 2405.13423](https://arxiv.org/pdf/2405.13423)

### Inferences
- Cost: equilibrated H(curl) estimators need one local constrained minimisation per vertex patch, with Nédélec/RT spaces of degree p (or p+1) on the patch, for each mode. This is embarrassingly parallel but more expensive than residual terms. A Prager–Synge bound for the eigenproblem would also need the source-problem reconstruction applied with right-hand side λ_h E_h, plus a separation (gap) assumption as in Cancès et al. No paper doing this for Maxwell was found.
- Guaranteed lower bounds for Maxwell eigenvalues are currently not usable at p2/p3 on curved, adaptively refined 3D meshes. The usable "certified" route is Barrenechea–Boulton–Boussaïd style enclosures, which cost extra shifted solves and work asymptotically.

### Gaps
- I found no equilibrated or Prager–Synge estimator analysed for the Maxwell eigenvalue problem, and no Maxwell extension of Cancès et al. (searches with 2024–2026 terms returned none). There may be very recent preprints (Chaumont-Frelet, Vohralík or Gedicke) that I did not find.
- No cost figures (CPU time per DOF) were found for the equilibrated H(curl) estimators.

## 3. Recovery (ZZ-type) estimators for H(curl)

### Takeaway
ZZ-type recovery for H(curl) exists for source problems. Nicaise (2005) recovers E and curl E by vertex-patch averaging into continuous piecewise polynomials, and the result is equivalent to the face jumps, without element residuals. Cai–Cao (2015) and Cai–Cao–Falgout (2016) give coefficient-robust recovery with H(curl)/H(div) recovery spaces plus an element residual. I found no recovery estimator analysed for the Maxwell eigenproblem. Using plain averaging for the eigenproblem is a heuristic.

### Cited Findings
- Nicaise, "On Zienkiewicz–Zhu error estimators for Maxwell's equations", C. R. Acad. Sci. Paris (2005): two quantities related to u and ∇×u are recovered in the continuous piecewise polynomial space by vertex-patch averaging. "The resulting ZZ estimator consisting of two terms is shown to be equivalent to the face jumps across the element faces. The element residuals are not included" (as described by Cai–Cao) — [Cai–Cao arXiv 1504.00898](https://arxiv.org/pdf/1504.00898)
- Cai & Cao, "A recovery-based a posteriori error estimator for H(curl) interface problems", CMAME (2015), arXiv 1504.00898: lowest-order Nédélec. Local indicator η_K² = η_{K,⊥}² + η_{K,0}² + η_{K,R}², with η_{K,⊥} = ||μ^{1/2}σ*_h − μ^{-1/2}∇×u_h||_K (recovered curl in H(curl)), η_{K,0} = ||β^{-1/2}τ*_h − β^{1/2}u_h||_K (recovered βu in H(div)), and η_{K,R} = μ_K h_K||f − βu_h − ∇×σ*_h||_K. Reliability and efficiency constants are independent of coefficient jumps under assumptions. Lemma 4.12: η_{K,0} is equivalent to the weighted normal jumps h_F^{1/2}||[[βu_h·n]]|| — [arXiv 1504.00898](https://arxiv.org/pdf/1504.00898)
- Cai, Cao, Falgout, "Robust a posteriori error estimation for finite element approximation to H(curl) problem", CMAME (2016): recovery for inhomogeneous media with L² right-hand side, plus an alternative recovery by localising the error flux — [ScienceDirect](https://www.sciencedirect.com/science/article/abs/pii/S0045782516305175); [OSTI](https://www.osti.gov/pages/biblio/1466146)

### Inferences
- The recovery term ||E_h − R E_h|| with R the averaging into continuous vector polynomials controls the full jump of E_h (normal and tangential). For Nédélec E_h the tangential part is already continuous, so ||E_h − R E_h|| is a proxy for the normal-jump (kernel) term of BGRS. ||curl E_h − R curl E_h|| is a proxy for the tangential-jump-of-curl term. A ZZ indicator on (E, curl E) therefore has the same jump content as the BGRS residual estimator but lacks the element residual h_K||E_h − curl curl E_h/λ_h||, which is non-zero for p ≥ 1. This is consistent with Nicaise's equivalence result for the source problem (proven there; the eigenproblem transfer is not).
- For reference, this repository's `src/data_gen/adaptive.py` indicator is exactly this ZZ type: VectorH1(p) averaging of E_k and curl E_k, summed over the cluster, plus a wall term. It has no element residual. By the above, it is a heuristic in the Nicaise class, not one of the proven eigenproblem estimators.

### Gaps
- Whether the NGSolve documentation uses ZZ recovery for Maxwell (as it does for Poisson) was not checked online. No published analysis of ZZ recovery for Maxwell eigenvalues or for p ≥ 2 Nédélec elements was found.

## 4. Curved elements / geometric error; re-entrant edges and corner singularities; uniform vs adaptive rates

### Takeaway
All eigenproblem estimator analyses found assume Lipschitz polyhedral domains with straight elements. I found nothing that adds a geometric-error term for curved (isoparametric) boundaries in the Maxwell eigenvalue setting. On re-entrant-edge domains (Fichera), uniform lowest-order meshes give |λ − λ_h| ~ N^{-0.44 to -0.45}. Adaptive meshes driven by the residual estimators recover the optimal N^{-2/3} (fitted slopes −0.66 to −0.79). Boffi–Gastaldi prove the optimal rate for AFEM in 3D, including the doubled eigenvalue rate.

### Cited Findings
- BGRS 2017, Fichera Ω = (0,0.8)×(0,1)×(0,1.2) ∖ (0,0.4)×(0,0.5)×(0,0.6), lowest-order edge elements, first positive eigenvalue λ ≈ 12.92: uniform meshes |λ − λ_h| ≈ C N^{-0.44} = C h^{2t} with t = 0.66; adaptive from 578 elements, fitted slope −0.79, optimal −2/3 — [arXiv 1602.00675](https://arxiv.org/pdf/1602.00675)
- BGRS 2019, Fichera (−1,1)³ ∖ [−1,0]³, ω² ≈ 3.220 (agrees with Dauge's benchmark page): uniform slope −0.45; adaptive from 581 elements, fitted slope −0.660 against the optimal −2/3 — [BGRS 2019 preprint](https://ci2ma.udec.cl/pdf/pre-publicaciones2/2017/pp17-15.pdf)
- Boffi & Gastaldi, "Adaptive finite element method for the Maxwell eigenvalue problem", SIAM J. Numer. Anal. 57(1) (2019), DOI 10.1137/18M1179389, arXiv 1804.02377. A standard solve–estimate–mark (Dörfler: θη̃² ≤ η̃²(M))–refine (newest-vertex-type admissible refinement) loop with the BGRS indicator converges at the optimal rate in 3D with respect to DOFs. The eigenvalue satisfies the "optimal double order rate". The identity used is λ − λ_h = ||σ − σ_h||² − λ_h||p − p_h||², and the hardest step is "discrete reliability". Assumptions: initial mesh fine enough, bulk parameter small enough, simple eigenvalue — [arXiv 1804.02377](https://arxiv.org/pdf/1804.02377)
- Regularity in polyhedra: the BGRS proofs use u, σ ∈ H^t(Ω) with t > 1/2 only — [BGRS 2019 preprint](https://ci2ma.udec.cl/pdf/pre-publicaciones2/2017/pp17-15.pdf)
- Liang, Xu, Zhang, "Adaptive multilevel methods for the Maxwell eigenvalue problem" (arXiv 2603.29718, Mar 2026). Uses the BGRS estimator μ_L²(u,K) = h_K²||u − curl(curl u/λ)||² + ½Σ_F{h_F||[[(curl u/λ) × n]]||² + h_F||[[u·n]]||²} (lowest order, div term zero) to drive a preconditioned Helmholtz–Jacobi–Davidson solver. Tests: Fichera, coil, multiply connected cavities (extra projection orthogonal to the harmonic fields needed), and a crack, where the adaptive rate "deteriorates". Simple principal eigenvalue assumed — [arXiv 2603.29718](https://arxiv.org/html/2603.29718)
- Barrenechea et al. obtained their Fichera enclosures on meshes refined along the re-entrant edges — [Strathprints PDF](https://strathprints.strath.ac.uk/50866/1/Barrenechea_etal_SIAMJSC_2014_Finite_element_eigenvalue_enclosures.pdf)
- The only isoparametric-Nédélec a posteriori work found is a source problem (adaptive DtN): lowest-order Nédélec with an isoparametric map that sends the boundary face exactly onto Γ_R — [arXiv 2202.09203](https://arxiv.org/pdf/2202.09203)

### Inferences
- The uniform rate N^{-0.44} ≈ h^{1.33} corresponds to E ∈ H^{t}, t ≈ 2/3, at a 270° edge. This is consistent with the leading singular behaviour E ~ r^{-1/3} (my reading; the exponent was not taken from a source above). Because the eigenvalue error is quadratic in the field error, uniform h-refinement saturates at h^{4/3} independent of p. Higher p pays off only with edge-graded or adaptive meshes.
- Localisation: the BGRS indicators concentrate along the re-entrant edges (their figures show the refinement there). This is expected: the normal-jump term dominates there because E_h cannot represent the r^{-1/3} normal component.
- Curved cavity walls: the theory treats the discrete domain as the true domain. On a curved p2 mesh the residual terms remain computable (element and face integrals on mapped elements), but nothing proves that they bound the geometric error, i.e. the difference between the curved discrete wall and the CAD. A practical approach is to keep the geometric approximation order at least p (isoparametric) so that the geometric error is higher order, and to check it separately (e.g. pillbox analytic comparison). This is heuristic.

### Gaps
- No paper was found on a posteriori estimators for Maxwell eigenproblems on curved/isoparametric meshes, or on including the boundary-approximation error. No hp-adaptive (p ≥ 2) eigenproblem study on 3D singular domains with measured rates was found (Bürg's hp work is for source problems).
- No source located for the exact r^{-1/3} singular exponent statement (well known, e.g. from Costabel–Dauge, but not fetched here).

## 5. Eigenfunctions vs eigenvalues; clusters and degenerate eigenvalues

### Takeaway
The estimators are for the eigenfunction error in H(curl) (BGRS 2019) or L² (BGRS 2017). The eigenvalue error follows as |λ − λ_h| ≤ Cη² because it is quadratic in the field error, with higher-order terms ρ(h)·(error)² absorbed for h small. For multiple or clustered eigenvalues, the literature says to estimate the whole cluster (sum of indicators over all discrete modes of the cluster). Using a subset gives "degeneracy of convergence". Cluster-robust optimality is proven for mixed Laplace (which covers 2D Maxwell). For 3D Maxwell it is claimed to extend by the same arguments but is written out only for simple eigenvalues.

### Cited Findings
- Reliability for the eigenvalue: ||u − u_h||_curl ≤ Cη̃ and |ω² − ω_h²| ≤ Cη̃² for h small. In mixed form, ||σ − σ_h|| + ||p − p_h|| ≤ Cη + ρ_rel1(h)(·) and |λ − λ_h| ≤ Cη² + ρ_rel2(h)(||σ − σ_h|| + ||p − p_h||)², with ρ → 0 — [arXiv 1804.02377](https://arxiv.org/pdf/1804.02377)
- Exact error identity used in the analysis: λ − λ_h = ||σ − σ_h||²_0 − λ_h||p − p_h||²_0 (and the analogous identity between two meshes) — [arXiv 1804.02377](https://arxiv.org/pdf/1804.02377)
- "It is well understood that the convergence analysis of the adaptive scheme for eigenvalue problems has to consider multiple eigenvalues and clusters of eigenvalues in order to prevent suboptimal convergence. In particular, degeneracy of the convergence may be observed when the error indicator is computed by taking into account only a subset of the discrete eigenmodes approximating the eigensolutions we are interested in" — [arXiv 1804.02377](https://arxiv.org/pdf/1804.02377)
- Boffi, Gallistl, Gardini, Gastaldi, "Optimal convergence of adaptive FEM for eigenvalue clusters in mixed form", Math. Comp. 86 (2017), arXiv 1504.06418: h-adaptive RT/BDM of any fixed degree in 2D/3D for Laplace clusters, with optimal rates, cluster-robust. Through the H(curl) ≅ H(div) isomorphism in 2D, this covers 2D Maxwell — [AMS](https://www.ams.org/mcom/2017-86-307/S0025-5718-2017-03212-9/); [arXiv 1804.02377](https://arxiv.org/pdf/1804.02377)
- Gallistl, "An optimal adaptive FEM for eigenvalue clusters", Numer. Math. 130(3) (2015) 467–496 (reference [28] in Boffi–Gastaldi) — [arXiv 1804.02377](https://arxiv.org/pdf/1804.02377)
- Cancès et al. 2020: guaranteed bounds on the sum of the cluster eigenvalues and on the density-matrix (spectral projector) error, needing only a checkable spectral gap. Second-order elliptic operators only — [AMS](https://www.ams.org/journals/mcom/2020-89-326/S0025-5718-2020-03549-2)
- BGRS 2019 note that extrapolation can validate eigenvalues but not eigenfunctions, so their tests report eigenvalue errors only — [BGRS 2019 preprint](https://ci2ma.udec.cl/pdf/pre-publicaciones2/2017/pp17-15.pdf)
- Effectivity: μ² is an asymptotic upper estimate of ω² − ω_h² with constant C. The observed ratio μ²/error was 5.2–6.3, so the estimator overestimates the eigenvalue error by about 5–6× (lowest order, Fichera) — [BGRS 2019 preprint](https://ci2ma.udec.cl/pdf/pre-publicaciones2/2017/pp17-15.pdf)

### Inferences
- For degenerate cavity modes (TE11/TM11 pairs in axisymmetric cavities), the right indicator is Σ_{k∈cluster} η_K(E_{h,k})². The convergence check should use cluster-invariant quantities: the mean (or sum) of the eigenvalues, the spectral projector, and the trace of figures of merit. The project already does this.
- An unscaled residual estimator gives no calibrated eigenvalue error (C ≈ 5–6 observed at lowest order). The relative error estimate needs calibration, e.g. against analytic pillbox values, or a guaranteed equilibrated bound.

### Gaps
- No paper writes out cluster estimators for 3D Maxwell; this is stated as extendable but not done. No Maxwell eigenproblem paper reports effectivity indices for p ≥ 1.

## 6. Estimators for derived quantities: wall losses (Q0), peak surface fields

### Takeaway
I found no paper on a posteriori or goal-oriented (DWR) error estimation for Maxwell cavity figures of merit: wall-loss integrals for Q0, R/Q, or peak surface E/B. This is an open area. General eigenvalue DWR exists (Heuveline–Rannacher type), but no Maxwell or edge-element application was located.

### Cited Findings
- Targeted searches for DWR or goal-oriented estimation of Maxwell eigenproblems, cavity Q-factor or wall-loss functionals returned only general DWR literature (other PDEs) and the residual eigenproblem papers above — [MP-DWR arXiv 2209.06035](https://arxiv.org/pdf/2209.06035); [arXiv 1602.00675](https://arxiv.org/pdf/1602.00675)
- In general DWR practice, a more complex quantity of interest may need the adjoint on a finer mesh or at higher order, and the higher-order adjoint is often more efficient (finite-volume review) — [arXiv 1011.0368](https://arxiv.org/pdf/1011.0368)

### Inferences
- Wall loss P_c ∝ ∮ |n × H|² dS with H ∝ curl E: the error in P_c is first order in the boundary trace error of curl E, unlike the eigenvalue, which is second order. A volume-only estimator (BGRS or ZZ volume terms) therefore does not target it. A goal-oriented estimator would weight the residual by the adjoint of the functional J(E) = ∮_wall |curl E × n|², linearised at E_h. For the eigenproblem the adjoint is a shifted (λ_h) curl-curl source problem in the orthogonal complement of E_h. This derivation is my inference and has no literature source.
- Peak surface fields (max norms) have no rigorous estimator theory even for Laplace; only heuristics (local refinement where |curl E_h| or |E_h| peaks on the wall) are available.

### Gaps
- No peer-reviewed or arXiv result on error estimators for cavity Q0, R/Q, G or Epk/Bpk was found. Accelerator-code practice (e.g. SLAC Omega3P adaptive refinement) was not searched in detail.
- Heuveline–Rannacher DWR for eigenvalues (2001) was not fetched; its applicability to H(curl) is unverified.
